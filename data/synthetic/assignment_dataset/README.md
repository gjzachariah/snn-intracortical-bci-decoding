# Assignment dataset (CSIT 750, part c)

Synthetic centre-out reaching data, generated by `src/generate_data.py` (seed 0, 96 channels, 100 trials per direction = 800 trials). Re-create it with `python src/part_c_outputs.py`.

## spike_counts_movement_window.csv
One row per trial.

| column | meaning |
|---|---|
| trial_id | 0-799 |
| direction_index / direction | reach direction 0-7 = N, NE, E, SE, S, SW, W, NW |
| split | train / val / test (70 / 15 / 15 %, balanced across directions) |
| ch000 ... ch095 | number of spikes the channel fired during the 0.5 s movement phase |

## neuron_parameters.csv
The hidden settings of each synthetic neuron: baseline rate, tuning amplitude, preferred direction, and whether the channel is silent.

The full trial-by-time spike arrays (800 x 96 x 100) are stored as a compressed `.npz` file that is not uploaded to GitHub; it is rebuilt from the seed.
